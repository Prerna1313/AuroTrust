# Auro Donation Platform

Auro is a blockchain-based donation platform built using **Next.js**, **TypeScript**, and **Aptos**.  
The platform allows users to securely make donations using cryptocurrency while ensuring transparency and traceability.

⚠️ **Note:** This project is currently under development. Some features are incomplete, but a prototype is available.

## Features

- Secure blockchain-based donation system  
- Wallet integration (Aptos-compatible, Petra Wallet recommended)  
- Modern frontend built with React and Next.js  
- Responsive design for web and mobile  
- Dashboard for users to track donations (coming soon)
